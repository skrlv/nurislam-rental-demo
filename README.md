# Nurislam — интерактивная демоверсия

Демонстрация сайта премиального автопроката по утверждённому макету. Сайт: https://skrlv.github.io/nurislam-rental-demo/

## Что можно проверить

- Адаптивная главная страница: каталог, фильтры, аренда на часы, сутки и несколько дней.
- Проверка выбранного периода по тестовому календарю (МСК / UTC+3).
- Тестовая заявка → демо CRM → подтверждение или отмена → изменение доступности в каталоге.
- Календарь по автомобилям, ручные тестовые брони и блокировки.
- В CRM → «Автомобили» → «Добавить автомобиль» можно указать название, описание, категорию, видимость и фотографию. Фото JPG/PNG/WebP до 12 МБ уменьшается на устройстве; без фото используется заглушка. Добавленный автомобиль сразу доступен в каталоге, календаре и помощнике этого браузера. Существующие автомобили и фото можно редактировать.
- Бесплатный помощник по базе знаний: типовые вопросы, выбор периода естественными фразами, доступность в демо-календаре. Не языковая модель: никаких платных API, ключей, загрузки нейросетей или отправки диалогов на сервер.

## Границы первой версии

Это демонстрация, не действующий сервис бронирования. Все машины и изображения иллюстративные. Цены, город, залог, страховка, водитель и реальные условия не выдумываются.

CRM не имеет авторизации и содержит только локальные тестовые данные. Заявки сохраняются в localStorage текущего браузера и не отправляются владельцу. Между вкладками одного браузера изменения синхронизируются; между разными устройствами — нет. Не вводите настоящие данные клиентов. Новая заявка имеет статус pending и не гарантирует бронирование. Подтверждение проверяет пересечения периодов; границы интервалов полуоткрытые [начало, окончание).

Для рабочего сервиса необходимы подтверждённый автопарк и условия, общая серверная база, защищённый вход менеджера и атомарная проверка пересечений на сервере. Ключи администратора и API никогда не должны попадать в публичный репозиторий. Публичные коммерческие операции следует размещать на подходящем хостинге; здесь размещена демонстрация для просмотра и тестирования.

## Локальный запуск и тесты

```sh
python3 -m http.server 4173 --bind 127.0.0.1
# Открыть http://127.0.0.1:4173/
node --test tests/*.test.mjs
```

Сборщик и установка зависимостей не нужны. Все пути относительные, поэтому сайт работает в подпапке GitHub Pages. `crm.html` открывает демонстрационную CRM. Для возврата к исходным тестовым данным используйте кнопку восстановления в CRM.

## Производительность и доступность

Локальные шрифты Manrope (OFL), адаптивные WebP-изображения, отложенная загрузка каталога, нулевые внешние сетевые зависимости во время работы. Клавиатурная навигация, подписанные поля, сообщения об ошибках и поддержка prefers-reduced-motion. Проверенные сценарии и размеры описаны в VALIDATION.md.

Сравнение помощников и источники: [RESEARCH.md](RESEARCH.md). Изображения созданы встроенным Imagegen; [промпты](ASSETS.md).
